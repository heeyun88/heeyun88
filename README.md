# Aurora · 티스토리 스킨

최신 트렌드를 반영한 모던하고 역동적인 티스토리 스킨 **Aurora** 입니다.

## 파일 구조

```
├─ index.xml     스킨 정보 (스킨 옵션/홈 커버/기본 설정)
├─ skin.html     메인 템플릿
├─ style.css     스타일
└─ images/
    └─ aurora.js  인터랙션 스크립트 (테마 전환/검색/목차/더 보기/슬라이더 등)
```

`tools/preview/` 는 로컬에서 스킨을 미리 보기 위한 파이썬 미리보기 도구이며,
티스토리에 업로드할 때는 업로드하지 않아도 됩니다.

## 티스토리에 적용하는 법

1. 티스토리 관리자 → 꾸미기 → 스킨 변경 → **스킨 등록**
2. **추가** 버튼을 눌러 다음 파일을 모두 선택해 업로드합니다.
   - `index.xml`, `skin.html`, `style.css` (기본 3파일)
3. 다시 **추가**를 눌러 `images/` 폴더 안의 파일을 업로드합니다.
   - `images/aurora.js`  (필수)
   - (커버/배너/슬라이더 등에 넣을 개인 배경 이미지가 있다면 images 폴더에 추가)
4. **저장** 후 스킨 이름을 `Aurora` 등으로 지정해 저장 → **적용**
5. 적용 후 블로그 설정에서 다음을 권장합니다.
   - 꾸미기 → 홈 커버 설정: 스킨에서 제공하는 `메인 슬라이더`, `카드 그리드`, `가로 스크롤 캐러셀`, `가로형 리스트`, `배너` 를 원하는 순서·개수로 배치
   - 스킨 옵션에서 대표 색, 테마, 글 목록 레이아웃 등을 취향에 맞게 조절
   - 사이드바(사이드바 위젯)에서 원하는 위젯(공지사항·최근글·인기글·방문자수·태그·달력·보관함)을 켜거나 끄기
   - 목록 페이지당 글 수: 9개 권장

## 주요 기능

- ✅ 라이트/다크 모드 전환 (시스템 설정 따르기 지원 · 방문자 선택 기억)
- ✅ Ctrl+K / ⌘K 빠른 검색 패널 (최근 검색어·추천 태그)
- ✅ 반응형 (데스크톱·태블릿·모바일 완전 대응)
- ✅ 홈 히어로(키워드 순환 · 통계 · 떠 있는 카드 스택)
- ✅ 슬라이더 · 카드 그리드 · 가로형 리스트 · 캐러셀 · 배너 커버
- ✅ 흐르는 태그 마키
- ✅ 매거진/카드/리스트 목록 뷰 전환 + 더 보기 로딩
- ✅ 글 자동 목차(TOC) + 읽기 진행 바 + 예상 읽기 시간
- ✅ 공유 버튼(링크 복사, 네이버/페이스북/X, 네이티브 공유)
- ✅ 마우스 스포트라이트·스크롤 등장 등 부드러운 모션 (동작 줄이기 자동 대응)
- ✅ 코드 복사 버튼 · 표 가로 스크롤 · 인용/제목/리스트 티포그래피 강화
- ✅ 다크 모드에서 에디터 글자색 자동 보정
- ✅ 티스토리 공감/공유/카테고리 다른 글 자연스러운 리스타일링
- ✅ 티스토리 기본 댓글/방명록 모듈 디자인 일체화
- ✅ jQuery 비의존 (순수 JavaScript)

## 로컬 미리보기 (선택)

```bash
cd tools/preview
python3 server.py               # http://localhost:8080
python3 server.py --lint        # 모든 화면 렌더링 치환자 검사
```

화면 왼쪽 아래의 **✦ 미리보기 화면 선택** 바를 이용해 홈·글·카테고리·태그·검색·공지·보호글·방명록 등
모든 페이지를 등록 전에 미리 확인할 수 있습니다. 실제 블로그 글/태그는 샘플 데이터로 채워집니다.

> 미리보기 서버에는 블로그 데이터가 없으므로 실제 글은 샘플 내용으로 표시됩니다.
> 실제 블로그에 적용하면 보유 중인 글·태그·카테고리·방문자 수로 자동 채워집니다.
